# EJB Portfolio

A responsive Vite + React portfolio for Emil John Benitez.

## Run it locally

```bash
npm install
npm run dev
```

## Customize it

- Edit project titles, descriptions, tags, and URLs in `src/projects.js`.
- Replace `your-email@example.com` in `src/App.jsx` with your real email.
- Update the skills or profile copy directly in `src/App.jsx`.
- Colors and layout are controlled by variables near the top of `src/styles.css`.

## Production build

```bash
npm run build
```
